# Demo Helena

Simulador de estudio del sistema Helena de ANMAT: el mostrador donde una empresa pide autorización para vender un producto médico.

No está conectado a ANMAT. Los trámites se guardan en el navegador y se borran con **Empezar de cero**.

## Cómo verlo

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Qué hay

- **La historia.** Cómo llega una empresa a Helena, antes de entrar.
- **El mostrador.** El recorrido del trámite, con datos de mentira.
- **Biblioteca.** Ejemplos públicos y lo que la demo marca como aprobado.
- **Qué falta.** Lo que la demo cubre y lo que todavía no está dibujado.
